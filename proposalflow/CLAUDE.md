# Claude Code - contexto do ProposalFlow

Antes de trabalhar neste projeto:

1. Leia `AGENTS.md` integralmente; ele é a regra canônica de engenharia.
2. Leia `SPEC.md` para conhecer o contrato atual do produto.
3. Use `AI_CONTEXT.md` como resumo, mas confirme tudo no repositório.
4. Consulte `docs/ARCHITECTURE.md` e `docs/DECISIONS.md` antes de introduzir uma decisão estrutural.

## Comportamento esperado

- Trabalhe orientado ao objetivo, não peça uma sequência de microtarefas.
- Comece inspecionando e planejando o impacto.
- Implemente apenas o escopo solicitado.
- Execute as validações relevantes e corrija falhas antes de concluir.
- Ao final, informe mudanças, testes executados e riscos restantes.

Os arquivos em `prompts/` são etapas independentes da oficina. Não antecipe o conteúdo de um prompt futuro.
