# Objetivo 3 - Revisar sem alterar

Atue como revisor independente. Não altere arquivos.

Leia a especificação, as instruções do projeto, a implementação e os testes. Procure:

- violações de requisitos;
- cálculos ou transições de estado incorretos;
- edge cases sem cobertura;
- vulnerabilidades e vazamento pelo link público;
- inconsistências entre backend, interface e persistência;
- dependências ou abstrações desnecessárias;
- testes ausentes, frágeis ou que validam a interpretação errada.

Para cada achado, apresente evidência concreta, impacto, prioridade e uma recomendação de correção. Diferencie fatos observados de hipóteses. Se não encontrar problema em uma área, diga o que foi verificado; não invente achados para preencher a revisão.
